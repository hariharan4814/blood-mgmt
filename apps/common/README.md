# Common Module (`apps.common`)

The `apps.common` module provides shared base utilities, common mixins, health-check endpoints, and cross-cutting infrastructure for the **Blood Management System**.

## Features in this Module
- **Health Check Endpoint**: `/api/health/` returns `{"status": "healthy"}`.
- **Root Project Documentation**: For the complete project documentation, system architecture, installation instructions, RBAC permissions matrix, and full API references, see the root [README.md](../../README.md).
